# Meeting Audio ASR / 会议录音与本地转写

Windows 桌面工具，录制麦克风和电脑播放声，后台分段转写。支持导入音频、手动纪要、托盘运行和异常恢复。不录视频，不将音频上传云端。

## 功能

- 默认开启麦克风与电脑声音，可在录制中分别开关。
- 开始时尝试识别腾讯会议/钉钉活动音频设备，否则优先使用健康的实体麦克风/扬声器，避免拔耳机后误选虚拟声卡或无活动的显示器输出；保留手动选择。
- 以播放声为参照抑制麦克风中的相关回声，并适度降低背景噪声。
- 约每 3 秒保存独立原始音频片段，后台进行离线识别。已保存的识别段落在最终汇总时不改写。
- 支持 MP3、WAV、M4A、FLAC 等音频导入，保留原文件和内部恢复副本。
- “简要记录”窗口支持自动保存。只有存在非空白内容时才生成 `纪要.txt`；清空内容后移除本场纪要文件。
- 关闭主窗口收进托盘。`--background` 可在启动时隐藏窗口，不自动开始录音。

## 安装运行

环境：Windows 10/11 x64，Python 3.12（包含 Tkinter），CPU 推理。

在仓库根目录运行 PowerShell：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe setup_models.py
.\.venv\Scripts\pythonw.exe _app\meeting_asr.py
```

首次安装依赖和模型需要联网。之后录音、识别和导入在本地运行。模型下载脚本校验 SHA-256；大型模型不存入 Git。

可选：创建桌面快捷方式及当前用户的登录自启动：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install_shortcuts.ps1 -Autostart
```

不指定 `-Autostart` 时仅创建桌面快捷方式。启动快捷方式使用 `--background`，录音必须手动开始。

## 使用

1. 打开工具，保持设备为“自动”。确认显示的麦克风与耳机/扬声器符合预期。
2. 点击“开始录音”，需要时打开“简要记录”输入要点与待办。
3. 点击“结束并转写”，等待剩余片段识别和音频文件生成。
4. 点击“打开文件夹”查看音频、转写及有内容时的纪要。

导入已有文件：点击“导入音频并转写”，无需开启录音设备。

## 本地数据

程序以仓库根目录（`_app` 的上一级）作为保存根目录：

```text
YYYY-MM-DD/HH-MM-SS-mmm_会议名称/
  会议音频.mp3
  会议音频.wav
  转写.txt
  纪要.txt          # 仅有手动记录内容时生成
_app/recordings/    # 原始片段、导入副本、处理结果和恢复进度
_app/models/        # 本地模型
```

MP3 为 64 kbps；WAV 为 16 kHz、16-bit 单声道。日期目录、模型、录音、转写、手记和设备配置均由 `.gitignore` 排除。不要删除内部恢复数据后再尝试恢复。

## 限制

- 会议软件内部静音不保证同步到独立录音工具。默认两路开启可能录下尚未发送到会议里的本地声音。
- 自动设备识别依赖 Windows 音频会话，不能保证所有软件版本都可识别。录制期间不自动切换设备；更换设备后应结束并重新开始。
- 回声抑制与降噪并非完美，旁边的人讲话仍可能被录下；未录到的内容无法恢复。
- 识别速度取决于 CPU 和系统负载，繁忙时可能积压。回听音频的合并与编码仍在结束阶段执行。
- 突然断电或磁盘故障时，最后未落盘的数据仍可能丢失。异常后可从“恢复未完成录音”继续处理。
- 本地/远端仅代表录音来源，不是说话人身份识别。关键数字、人名、术语请结合原音核对。
- 同一 Windows 用户只运行一个实例。

## 验证

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

仓库测试使用合成音频及临时文件，不包含真实会议内容。开发时另行验证过音频导入、后台识别、回声抑制和 UI 状态；测试结果不能替代真实设备验收。

## 模型与依赖

识别采用 sherpa-onnx 的离线 Paraformer int8，语音活动检测采用 Silero VAD。模型来源、固定版本与校验值见 `models-manifest.json`。音频降噪通过 pywebrtc-audio，音频编解码使用 imageio-ffmpeg。各第三方组件及模型遵循各自的许可证。
